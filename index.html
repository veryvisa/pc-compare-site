第一步

你是哪种情况

点一下，下面的查找器会切到对应的类别和省份，并按这种情况最该先看的那一点排好；还没收录产品的类别直接带你去类别页。

刚落地，租房住房东的保险不保你的东西，也不保你给别人造成的损失。租客险先看个人责任额度。常见误解：我东西不多，租客险没必要买；房东有保险，我的东西和责任也在里面看租客险怎么比 →
买了 Condo大楼 Strata 保单只管外壳和公共部分。先问大楼自付额，再看你的分摊额度够不够。常见误解：买了 Condo，大楼有 Strata 保单就够了；大楼理赔的自付额是 Strata 的事，跟我无关看Condo 公寓险怎么比 →
自住独立屋水从哪来决定赔不赔，BC 地震要单独加。先看水损三件事有没有都加上。常见误解：地下室进水都算「水损」，房屋险都会赔；在 BC 买了房屋险，地震就自动包含在内看自住房屋险怎么比 →
有出租房地下室套间、整套出租、Airbnb 短租，自住保单都不够，出租前要先告诉保险公司。常见误解：房子或 Condo 租出去，原来的自住保单照样有效；偶尔挂 Airbnb 短租几晚，不用跟保险公司说看房东险怎么比 →
买车 · BC基本险只能在 ICBC 买；碰撞、综合、延伸责任、逃逸车损这些附加险，可以在 ICBC 或 BC 本地私营公司之间比。先把海外驾龄证明带齐。常见误解：在 BC 可以找私营保险公司买全套车险比价；停着的车被人撞了跑掉，ICBC 基本险会赔修车；国内开了十年车，到加拿大驾龄都从零算在 BC 买附加车险可以找谁（带官方出处）→看车险怎么比 →
买车 · 安省 / 阿省全私营，同一个人几家报价差很多。海外驾龄各家认法不同，逐家问。常见误解：国内开了十年车，到加拿大驾龄都从零算；开 Uber、送外卖，用私家车保险就行看车险怎么比 →

出一次险，车险保费就一定涨

在 BC，影响基本险保费的是你有责任的事故，ICBC 按十年窗口看有责事故记录。非责事故、以及私营公司的附加险与房屋险怎么算，各有规则，报案前可以先问经纪。

为什么要紧：怕涨价而不报案，可能错过该拿的赔付，还违反报案义务

BC 基本险的第三者责任有 20 万，够用了

ICBC 基本险的第三者责任是 20 万元；撞坏豪车或严重伤人，赔偿很容易超过这个数。延伸第三者责任可加到最高 500 万元，属于附加险。

为什么要紧：超出保额的部分要自己赔，20 万在大温很容易被击穿

中国驾照开了两年以上，到 BC 直接就能换驾照

ICBC 免试换照名单是奥地利、澳洲、比利时、法、德、爱尔兰、日本、荷兰、新西兰、韩国、瑞士、台湾、英国等，没有中国大陆；名单外要考知识和路考。落地后可用原驾照开 90 天；驾龄够才能跳过 N 牌（门槛见阶梯驾照页）。

为什么要紧：以为能直接换，拖过 90 天才去考，中间就成了无有效驾照开车；落地就该约考试

停着的车被人撞了跑掉，ICBC 基本险会赔修车
